# Hazel Larcena | Portfolio

Static portfolio site (HTML + CSS, no build step) ready for GitHub Pages.

## Publish on GitHub Pages

1. Sign in to GitHub and create a new **public** repository.
   - Name it `YOUR-USERNAME.github.io` to get the URL `https://YOUR-USERNAME.github.io/`
   - Or name it `portfolio` to get `https://YOUR-USERNAME.github.io/portfolio/`
2. Upload these files to the repository root: `index.html`, `Hazel_Larcena_Resume.pdf`, `README.md`.
3. Go to **Settings → Pages**. Under **Build and deployment**, set Source to **Deploy from a branch**, Branch to **main**, folder **/ (root)**, then Save.
4. Wait 1–2 minutes. Your site will be live at the URL above.

## Customize

- Edit `index.html` in GitHub (pencil icon) or locally.
- Add projects: uncomment the `PROJECTS` block in `index.html` and fill it in.
- Add LinkedIn/GitHub links: add an `<a>` next to the email in the hero or contact section.
- Replace the resume: upload a new PDF with the same name `Hazel_Larcena_Resume.pdf`.
